# BEUM 배수로 인스턴스 세그멘테이션 어노테이션 가이드라인 (Labeling Guideline)

## 1. 개요 및 목적
본 가이드라인은 BEUM(가두리 배수구 모니터링 시스템)의 YOLOv8 세그멘테이션 데이터셋 구축 시, 어노테이터 간의 일관성(Inter-annotator consistency)을 확보하고 모델의 오탐(False Positive) 및 클래스 혼동을 최소화하기 위해 제정되었습니다.

---

## 2. 클래스 정의 및 의미 체계

| 클래스 ID | 클래스 명 | 대상 설명 | 판별 기준 |
|:---:|:---|:---|:---|
| **0** | `object` | 배수로 주변/내부의 단독 이물질 (페트병, 캔, 큰 쓰레기 등) | 배수로 내부 또는 인접한 도로면에 위치한 개별 장애물 |
| **1** | `drain_area` | 정상 배수로 (원활한 배수 가능 상태) | 철제 그레이팅(창살) 사이로 물이 빠질 수 있는 공간이 50% 이상 확보된 상태 |
| **2** | `drain_full` | 막힌 배수로 (침수 위험 상태) | 낙엽, 토사, 쓰레기 등으로 그레이팅 표면 또는 내부가 50% 이상 뒤덮여 배수가 불가능한 상태 |

> [!IMPORTANT]
> **`drain_area` vs `drain_full` 판별 핵심 원칙**
> - 동일한 물리적 배수구라도 **이물질 퇴적 비율 50%**를 기준으로 정상(`drain_area`)과 막힘(`drain_full`)을 구분합니다.
> - 부분 막힘(20~30% 낙엽)의 경우 `drain_area`로 마스킹하고, 덮고 있는 큰 쓰레기는 별도의 `object`로 라벨링합니다.
> - 화면상 하나의 배수구에 대해 `drain_area`와 `drain_full` 마스크를 겹쳐서 부여하지 않습니다 (단일 배수구 = 1개 클래스 부여).

---

## 3. 세그멘테이션 폴리곤 경계 작성 규칙

### 3.1 배수로 경계선(Boundary) 기준
- **철제 그레이팅 외곽선(Grating Frame)**을 기준으로 마스킹합니다.
- 주변 아스팔트나 콘크리트 테두리는 포함하지 않고, 물이 유입되는 **철제 빗물받이 구조물 본체**만을 밀착하여 폴리곤을 작성합니다.

```text
[잘못된 예시]                 [올바른 예시]
┌──────────────────┐         ┌──────────────────┐
│ 콘크리트 연석    │         │ 콘크리트 연석    │
│  ┌────────────┐  │         │  ┌────────────┐  │
│  │철제그레이팅│  │         │  │철제그레이팅│  │  <-- 여기만 밀착 마스킹
│  └────────────┘  │         │  └────────────┘  │
└──────────────────┘         └──────────────────┘
```

### 3.2 화면 밖 잘림(Truncated) 객체
- 화면 가장자리(좌/우/하단)에 의해 배수로의 일부만 보이는 경우:
  - 배수로의 형태가 **30% 이상 식별 가능**하면 보이는 부분만 폴리곤으로 마스킹합니다.
  - 형태 판별이 불가능할 정도로 작게 잘린 경우(30% 미만)는 라벨링하지 않고 제외합니다.

### 3.3 가려짐(Occluded) 객체
- 자동차 바퀴, 보행자, 나뭇가지 등으로 배수로가 일부 가려진 경우:
  - 가려진 부분을 제외하고 **실제 노출된 영역만 하나의 폴리곤** 또는 Multi-polygon으로 마스킹합니다.

---

## 4. Hard Negative (오탐 방지 배경 이미지) 규칙
다음 객체들은 **절대로 배수로(`drain_area`, `drain_full`)로 라벨링하지 말아야 하며**, 모델이 오탐할 경우 Hard Negative(빈 라벨)로 등록하여 학습시킵니다:
1. **맨홀 뚜껑(원형/사각 콘크리트/철제)**: 배수 구멍이 없는 일반 통신/상하수도 맨홀
2. **도로 균열 및 아스팔트 덧씌우기 흔적 (Crack/Patch)**
3. **가로등, 방음벽, 펜스 그림자 (Shadow)**
4. **비 온 뒤 노면 반사광 및 물웅덩이 (Reflection/Puddle)**
5. **도로 연석(Curb) 및 인도 경계석**
